# Keyword Map — uncensored-models

Primary entity: **Uncensored model**  
Primary category keyword: **Uncensored models**  
Primary technique keyword: **Abliterated models**

The repo deliberately covers the category, the technique and every individual model name together:

> **Uncensored models** is what people search for, **abliterated** is the weight-level technique behind many of them, and each model ID (`glm-5.3-abliterated`, `deepseek-v4.1-flash-abliterated`, …) is its own long-tail query answered by a page under `models/`.

This phrasing appears in the repo name, description, README intro, per-model pages and metadata so Google, DuckDuckGo and AI answer engines can associate all of them without keyword stuffing.

## Negative keywords (do not target)

- "Uncensored" for image/video generators — different product, different intent.

- Local model-running tutorials — the open-weights section links out, does not teach.
